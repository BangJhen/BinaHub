# Konteks Deskripsi Page “Lowongan Kerja” Glints

Halaman “Lowongan Kerja” pada [Glints Indonesia](https://glints.com/id/lowongan-kerja/?utm_source=chatgpt.com) merupakan sebuah job discovery platform modern yang dirancang untuk membantu pengguna menemukan pekerjaan secara cepat, personal, dan terfilter berdasarkan kebutuhan karier mereka. Halaman ini menggabungkan konsep job marketplace, intelligent filtering system, dan recommendation engine dalam satu tampilan yang clean serta mobile-friendly.

Secara visual, halaman menggunakan pendekatan modern minimalistic recruitment UI dengan dominasi whitespace, card-based layout, serta fokus utama pada pencarian pekerjaan dan eksplorasi lowongan.

---

## 1. Navigation/Header Section

Bagian atas halaman terdiri dari:

* Logo platform

  * Lowongan Kerja
  * Perusahaan
  * Blog
* Tombol:

Tujuan utama header:

# 2. Hero Search Section

Bagian paling penting dari halaman.

Terdapat search engine utama dengan beberapa input:

### Input Search

* Nama pekerjaan
* Skill
* Nama perusahaan

### Location Search

* Kota
* Provinsi
* Area kerja

### CTA Search Button

Tombol “Cari” dengan visual kontras.

Fungsi utama:

* membantu user melakukan job discovery secara cepat,
* menjadi pusat interaksi utama pada halaman.

Konsep UX:

* search-first experience,

# 8. UX Pattern yang Digunakan

## UX yang terlihat:

### Search-centric design

Fokus utama langsung pada pencarian kerja.

### Card-based architecture

Informasi disusun modular dan mudah discan.

### Information hierarchy

Informasi penting seperti:

* posisi,
* gaji,
* lokasi,
  lebih dominan dibanding informasi sekunder.

### Infinite exploration

User dibuat terus mengeksplor lowongan melalui:

* rekomendasi,
* kategori,
* filter.

### Mobile-first approach

Layout dibuat ringan dan cocok untuk aplikasi mobile.
